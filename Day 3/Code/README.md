# 📅 Day 3: Java Conditional Statements

> **Learning Motto:** *Learn → Code → Practice → Build → Revise*

## 📖 Overview
Today's focus was on **Decision-Making Statements** in Java. These statements are the backbone of program logic, allowing applications to make dynamic decisions and control the flow of execution based on specific conditions.

---

## 🚀 Topics Covered

| Statement | Description |
| :--- | :--- |
| **`if`** | Executes a block of code only when a condition evaluates to `true`. |
| **`if-else`** | Executes one block when the condition is `true`, and another when `false`. |
| **`else-if` Ladder** | Checks multiple conditions sequentially until one evaluates to `true`. |
| **Nested `if`** | An `if` statement placed inside another `if` statement for complex logic. |
| **`switch`** | Selects a single execution path from multiple fixed, discrete options. |

---

## 💡 Important Concepts & Key Learnings

- **Conditional Logic:** Mastered how to control program execution flow based on dynamic conditions.
- **Operators:** Practiced Comparison (`>`, `<`, `==`, `!=`) and Logical (`&&`, `||`, `!`) operators.
- **String Comparison:** Learned the crucial difference between `==` (compares memory references) and `.equals()` (compares actual string content).
- **Switch Mechanics:** Understood the importance of the `break` keyword to prevent fall-through, and the `default` case for handling unexpected inputs.
- **Use Cases:** Clarified when to use `if-else` (for ranges and complex conditions) vs. `switch` (for exact value matching).

## 🛠️ Practical Exercises

### Exercise 1: Age Eligibility Checker
**Objective:** Check whether a person is eligible to vote based on their age.
- Used an `if-else` statement to evaluate the age.
- **Condition:** If age >= 18 → Eligible; Otherwise → Not Eligible.

### Exercise 2: Login Validation
**Objective:** Validate a username and password to simulate a login screen.
- Used the logical AND (`&&`) operator to check both credentials simultaneously.
- Used `.equals()` for secure and accurate String comparison.
- Displayed success or invalid credential messages based on the input.

### Exercise 3: Grade Calculator
**Objective:** Calculate a student's letter grade based on their numerical marks using an `else-if` ladder.

| Marks | Grade |
| :---: | :---: |
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | Fail |

### Exercise 4: Banking Menu
**Objective:** Create a simple interactive banking menu using a `switch` statement.
- **Option 1:** Deposit Money
- **Option 2:** Withdraw Money
- **Option 3:** Check Balance
- **Default:** Invalid Option (Handled using the `default` case).
